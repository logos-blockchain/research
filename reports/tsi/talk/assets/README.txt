Drop your memes and video clips in this folder.

    1.*   opener
    2.*   after "it guesses low"
    3.*   after "count slots, not blocks"
    4.*   closer

Name them 1, 2, 3, 4. Any of these extensions works, video is tried first:

    mp4  webm  mov  m4v  gif  png  jpg  jpeg  webp  avif

A slot with no file removes its own slide, so the deck always presents cleanly
whether you fill none of them or all four.

Meme captions live on the media slides in tsi-talk.html as the data-top and
data-bottom attributes -- search the file for `data-media` to find them.
Leave both empty for a plain clip with no caption.
